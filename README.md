# Khubza & Za'atar

Website for a small Palestinian bakery in Cairo, run by bakers from Gaza. Manakish and pastries, baked fresh to order.

**Live:** https://mahassira.github.io/KHUBZAandZAATAR/

Visitors can browse the menu, read the story, and send an order. Orders go straight into a Google Sheet through a small Apps Script (`apps-script/Code.gs`), so the bakery doesn't need a server.

Arabic and English. Built with HTML, CSS and JavaScript.
